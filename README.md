# PainScout AI 🚀

PainScout AI — это инструмент на Python для автоматического сбора актуальных потребностей и «болей» разработчиков из открытых источников (Hacker News), помогающий генерировать идеи для контента, маркетинга и запуска цифровых продуктов (SaaS, китов и шаблонов).

## 📋 Требования
- Python 3.8+
- Библиотека `requests`
